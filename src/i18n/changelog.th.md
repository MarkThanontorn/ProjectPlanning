# บันทึกการเปลี่ยนแปลง

ฉบับภาษาไทยสำหรับแสดงในแอพ (ฉบับหลักบน GitHub คือ `CHANGELOG.md` ภาษาอังกฤษ)

- **เปลี่ยนใหญ่** (`2.0.0`) — เปลี่ยนรูปแบบข้อมูล หรือวิธีใช้งานหลัก
- **เปลี่ยนกลาง** (`1.1.0`) — เพิ่มฟีเจอร์ใหม่
- **เปลี่ยนเล็ก** (`1.0.1`) — แก้บั๊ก ปรับหน้าตาเล็กน้อย

รุ่นก่อน 1.0.0 เขียนย้อนหลังจากประวัติการพัฒนา (วันที่เป็นค่าประมาณ)
มีโค้ดใน Git ตั้งแต่ 1.0.0 เป็นต้นไป รุ่นก่อนหน้าจึงอ่านได้แต่ย้อนโค้ดกลับไปไม่ได้

## [2.0.1] — 2026-10-20
เพิ่มความปลอดภัย
- โหมดทีมตรวจไฟล์ของสมาชิกทุกไฟล์ก่อนใช้: ข้ามรายการที่รูปแบบผิด แปลงค่าให้ถูกชนิด
  และไม่รับรายการที่อ้างว่าเป็นของคนอื่น ไฟล์ที่เสียหายในโฟลเดอร์ทีมจะไม่ทำให้แอพค้างอีก
- การนำเข้าไฟล์สำรอง .json ผ่านการตรวจแบบเดียวกัน
- ส่งออก CSV: ข้อความที่ขึ้นต้นด้วย `=`, `+`, `-` หรือ `@` จะยังเป็นข้อความ ไม่กลายเป็นสูตรเมื่อเปิดใน Excel
- เพิ่ม Content Security Policy ทั้งเว็บและไฟล์ .html: แอพโหลดได้เฉพาะโค้ด สไตล์ และฟอนต์ของตัวเอง
  และส่งข้อมูลไปเว็บอื่นไม่ได้
- ฟอนต์ (IBM Plex Sans Thai) ฝังอยู่ในแอพแทนการโหลดจาก Google Fonts — หลังโหลดแอพแล้วไม่มีการติดต่ออินเทอร์เน็ตเลย

## [2.0.0] — 2026-10-19
โหมดทีม: ใช้แผนเดียวกัน 2–3 คนผ่านโฟลเดอร์ OneDrive / Box — ไม่ต้องมีเซิร์ฟเวอร์
- เข้าร่วมได้จากแถบซ้าย ("โหมดทีม") หรือหน้าต้อนรับ: ใส่ชื่อ แล้วเลือกโฟลเดอร์ที่แชร์กัน (Edge / Chrome)
  คนแรกใช้ข้อมูลในเครื่องเป็นข้อมูลตั้งต้นของทีม คนที่เข้ามาทีหลังเลือกใช้ข้อมูลทีม
  หรือรวมข้อมูลของตัวเองเข้าไปได้ (ดาวน์โหลดไฟล์สำรอง .json ให้ก่อน)
- แต่ละคนเขียนเฉพาะไฟล์ของตัวเอง แอพรวมการแก้ไขของทุกคนเป็นรายช่อง
  แก้คนละช่องของงานเดียวกันจะไม่ทับกัน
- ปุ่ม "Sync" และซิงก์อัตโนมัติทุก 1 นาทีและเมื่อกลับมาที่หน้านี้
  แถบซ้ายแสดงสมาชิก เวลาบันทึกล่าสุด และใครออนไลน์อยู่
- แก้ชนกัน: ถ้าสองคนแก้ช่องเดียวกันโดยยังไม่เห็นการแก้ของอีกคน จะแจ้งเตือนทั้งคู่
  แสดงค่าของแต่ละคนพร้อมชื่อและเวลา แล้วให้เลือกค่าที่จะเก็บ (ระหว่างนี้แสดงค่าล่าสุดไว้ก่อน)
  กรณีลบชนกับแก้ไขก็เช่นกัน (ยังไม่ลบจนกว่าจะเลือก)
- ประวัติการแก้ไขของแต่ละงาน (ใคร แก้อะไร เมื่อไหร่) และปุ่ม "ใช้ค่านี้" เพื่อย้อนค่า
- รายการที่ถูกลบ: ดูทุกอย่างที่ถูกลบในทีม และกู้คืนพร้อมรายการที่ถูกลบไปด้วยกัน
- แจ้งว่ามีคนกำลังแก้: ระหว่างที่มีคนแก้งานในหน้ารายละเอียด คนอื่นจะเห็น "🔒 … กำลังแก้งานนี้"
  (และที่ชื่อใน WBS) กด "แจ้งเมื่อแก้เสร็จ" ได้ และไม่ถูกห้ามแก้
  ล็อกหมดอายุเอง (ไม่มีสัญญาณ 5 นาที หรือไม่ได้พิมพ์ 10 นาที)
- ของส่วนตัวยังเป็นของแต่ละคน: รายการวันนี้, Highlight, กิจวัตร, การย่อแถว และการตั้งค่า
- ออกจากโหมดทีมแล้ว ข้อมูลล่าสุดยังอยู่ในเครื่อง

## [1.1.1] — 2026-10-18
