# บันทึกการเปลี่ยนแปลง

ฉบับภาษาไทยสำหรับแสดงในแอพ (ฉบับหลักบน GitHub คือ `CHANGELOG.md` ภาษาอังกฤษ)

- **เปลี่ยนใหญ่** (`2.0.0`) — เปลี่ยนรูปแบบข้อมูล หรือวิธีใช้งานหลัก
- **เปลี่ยนกลาง** (`1.1.0`) — เพิ่มฟีเจอร์ใหม่
- **เปลี่ยนเล็ก** (`1.0.1`) — แก้บั๊ก ปรับหน้าตาเล็กน้อย

รุ่นก่อน 1.0.0 เขียนย้อนหลังจากประวัติการพัฒนา (วันที่เป็นค่าประมาณ)
มีโค้ดใน Git ตั้งแต่ 1.0.0 เป็นต้นไป รุ่นก่อนหน้าจึงอ่านได้แต่ย้อนโค้ดกลับไปไม่ได้

## [2.4.0] — 2026-11-04
- Status กับความคืบหน้าตรงกันเสมอไม่ว่าเปลี่ยนจากฝั่งไหน: รอคิว = 0%, กำลังทำ / รอตรวจ = ระหว่างนั้น,
  เสร็จแล้ว = 100% ข้อมูลเดิมจะถูกปรับให้ตรงตอนเปิดแอพ
- WBS: รายละเอียดและหมายเหตุเปิดเป็นกล่องใหญ่ อ่านและเขียนได้หลายบรรทัด
- งานที่เสร็จแล้วเป็นตัวอักษรสีเทา ทั้งใน WBS, รายการงาน และการ์ด
- ระบุว่างาน "ไม่เกี่ยวข้อง" ได้ (หน้ารายละเอียด, WBS, Gantt): นับเป็นเสร็จ 100% มีป้ายกำกับ
  และยกเลิกแล้วกลับเป็นค่าเดิม
- กรองตามผู้รับผิดชอบได้ใน WBS และ Gantt (แสดงโปรเจกต์และกลุ่มของงานนั้นด้วย)
- การ์ด: ชื่องานเป็นหัวข้อ ส่วนโปรเจกต์ / กลุ่มเป็นตัวเล็กสีเทาบรรทัดล่าง
- การ์ด: ปุ่ม ☀ เพิ่มงานเข้าวัน และ ☆ ตั้งเป็น Highlight
- การ์ดที่เอาออกจากบอร์ดคงสถานะและความคืบหน้าไว้ และกลับมาในสัปดาห์ที่มีแผนหรือกำหนดส่ง
- Gantt: คลิกชื่อเพื่อเปิดรายละเอียด โปรเจกต์และกลุ่มมีหน้ารายละเอียดแล้ว และงานมีช่องหมายเหตุ
- Gantt: คลิกแถว Project / Group เพื่อเพิ่ม Milestone ในวันที่คลิก (แถวกลุ่มจะเพิ่มเข้าโปรเจกต์ของกลุ่มนั้น)
- Gantt: คลิกขวาที่แถวเพื่อตั้ง ย้าย หรือลบ Due Date
- ชื่อไฟล์ส่งออกและสำรองข้อมูลมีเวลาถึงหลักนาที
- แก้ชื่อยาวที่ขยับไปทางซ้ายใน WBS และ Gantt

## [2.3.0] — 2026-11-04
- บอร์ด: "เรียงตาม" ลำดับความสำคัญ, Rank, กำหนดส่ง, Plan End, ความคืบหน้า หรือชื่องาน ทั้งน้อยไปมากและมากไปน้อย
  ใช้กับคอลัมน์ทั้งหมด, คอลัมน์วัน, คอลัมน์สถานะ และ Matrix และจำค่าไว้
- บอร์ด: เอาการ์ดออกจากบอร์ดสัปดาห์นี้ได้ด้วยปุ่ม ✕ หรือลากไปคอลัมน์ทั้งหมด ยังเห็นในคอลัมน์ทั้งหมด / WBS / Gantt
  ลากกลับเข้าคอลัมน์สถานะหรือเริ่มจับเวลาก็จะกลับมาทันที
- การ์ดแสดงเช็คลิสต์ของงาน และติ๊กบนการ์ดได้เลย
- หน้ารายละเอียดงาน: งานที่เสร็จแล้วกด "ยังไม่เสร็จ" เพื่อเปิดกลับมาได้
  และกดเริ่มจับเวลางานที่เสร็จแล้วก็จะลดจาก 100% เป็น 95%
- วันที่แสดงเป็น YYYY/MM/DD ทั้งหมด ช่องวันที่พิมพ์ได้ (2026/11/04, 2026-11-4, 20261104) หรือกดปุ่มปฏิทิน
- Gantt: โฟกัสสัปดาห์นี้ หรือ 2 สัปดาห์ พอดีหน้าจอ และแสดงเฉพาะงานในช่วงนั้น
- Gantt: ลากขอบคอลัมน์ชื่อเพื่อปรับความกว้าง (ดับเบิลคลิกเพื่อรีเซ็ต)
- Gantt: ปุ่ม "+" แสดงตลอดที่ชื่อ Project / Group และข้อความใต้ตารางอธิบายการตั้งแผนแทน
- WBS และ Gantt: ปุ่มย่อทั้งหมด / ขยายทั้งหมด
- Leadtime: เครื่องหมายกรอกเองเป็นไอคอนดินสอเล็กๆ (ชี้เมาส์เพื่อรีเซ็ต)

## [2.2.0] — 2026-10-25
- แยก Project / Group / Task ด้วยรูปแบบตัวอักษรแทนสี ทั้งใน WBS และ Gantt:
  Project = ตัวหนาเอียง ขีดเส้นใต้ และมีเส้นคั่นด้านบน, Group = กึ่งหนาเอียง, Task = ตัวปกติ (ขนาดเท่ากันทั้งหมด)
  (สีใช้สำหรับสถานะและความคืบหน้าเท่านั้น)
- Bar ใน Gantt ชัดขึ้น: งานที่ยังไม่เริ่มเป็นสีฟ้าทึบ, เลยกำหนดเป็นสีแดง, เสร็จแล้วเป็นสีเขียว
  Bar สรุปของ Project / Group เป็นสีเทา ขนาดเท่ากัน
- Gantt แสดงธง ⚑ กลางช่องวัน Due Date (สีเหลือง = ยังไม่ถึง, แดง = เลยแล้ว, เขียว = เสร็จแล้ว)
  ลากธงซ้าย/ขวาเพื่อเลื่อน Due Date และคลิกธงเพื่อเปิดงาน
- Gantt โหมดวัน: คลิกวันในแถวของงาน = ตั้งแผนของงานนั้น (ยังไม่มีแผน = วันนั้นวันเดียว,
  ก่อนวันเริ่ม = เลื่อนวันเริ่ม, นอกนั้น = เปลี่ยนวันจบ) และคลิกในแถว Project / Group จะไม่สร้างงานใหม่แล้ว
- Gantt: ปุ่ม "+ งาน" ข้าง "+ กลุ่ม" ที่ชื่อ Project / Group
- Gantt: ลากแถวที่ปุ่ม ⠿ เพื่อสลับตำแหน่ง หรือย้ายเข้า Project / Group อื่นได้ (เหมือน WBS)
- WBS: หัวตารางค้างไว้ด้านบนเวลาเลื่อน และแถบเลื่อนซ้าย-ขวาอยู่บนจอตลอด (เหมือน Gantt)
  ตารางทั้งสองพอดีหน้าจอแม้มีแถบแจ้งเตือนด้านบน
- WBS: คอลัมน์อย่าง Progress ไม่ทับคอลัมน์ชื่อเวลาเลื่อนซ้าย-ขวาอีก
- Dropdown, ตัวเลือกวันที่ และแถบเลื่อน เปลี่ยนเป็นสีมืดตามโหมดมืด
- ปุ่มเปลี่ยนภาษาเป็น TH / EN

## [2.0.1] — 2026-10-20
เพิ่มความปลอดภัย
- โหมดทีมตรวจไฟล์ของสมาชิกทุกไฟล์ก่อนใช้: ข้ามรายการที่รูปแบบผิด แปลงค่าให้ถูกชนิด
  และไม่รับรายการที่อ้างว่าเป็นของคนอื่น ไฟล์ที่เสียหายในโฟลเดอร์ทีมจะไม่ทำให้แอพค้างอีก
- การนำเข้าไฟล์สำรอง .json ผ่านการตรวจแบบเดียวกัน
- ส่งออก CSV: ข้อความที่ขึ้นต้นด้วย `=`, `+`, `-` หรือ `@` จะยังเป็นข้อความ ไม่กลายเป็นสูตรเมื่อเปิดใน Excel
- เพิ่ม Content Security Policy ทั้งเว็บและไฟล์ .html: แอพโหลดได้เฉพาะโค้ด สไตล์ และฟอนต์ของตัวเอง
  และส่งข้อมูลไปเว็บอื่นไม่ได้
- ฟอนต์ (IBM Plex Sans Thai) ฝังอยู่ในแอพแทนการโหลดจาก Google Fonts — หลังโหลดแอพแล้วไม่มีการติดต่ออินเทอร์เน็ตเลย

## [2.0.0] — 2026-10-19
โหมดทีม: ใช้แผนเดียวกัน 2–3 คนผ่านโฟลเดอร์ OneDrive / Box — ไม่ต้องมีเซิร์ฟเวอร์
- เข้าร่วมได้จากแถบซ้าย ("โหมดทีม") หรือหน้าต้อนรับ: ใส่ชื่อ แล้วเลือกโฟลเดอร์ที่แชร์กัน (Edge / Chrome)
  คนแรกใช้ข้อมูลในเครื่องเป็นข้อมูลตั้งต้นของทีม คนที่เข้ามาทีหลังเลือกใช้ข้อมูลทีม
  หรือรวมข้อมูลของตัวเองเข้าไปได้ (ดาวน์โหลดไฟล์สำรอง .json ให้ก่อน)
- แต่ละคนเขียนเฉพาะไฟล์ของตัวเอง แอพรวมการแก้ไขของทุกคนเป็นรายช่อง
  แก้คนละช่องของงานเดียวกันจะไม่ทับกัน
- ปุ่ม "Sync" และซิงก์อัตโนมัติทุก 1 นาทีและเมื่อกลับมาที่หน้านี้
  แถบซ้ายแสดงสมาชิก เวลาบันทึกล่าสุด และใครออนไลน์อยู่
- แก้ชนกัน: ถ้าสองคนแก้ช่องเดียวกันโดยยังไม่เห็นการแก้ของอีกคน จะแจ้งเตือนทั้งคู่
  แสดงค่าของแต่ละคนพร้อมชื่อและเวลา แล้วให้เลือกค่าที่จะเก็บ (ระหว่างนี้แสดงค่าล่าสุดไว้ก่อน)
  กรณีลบชนกับแก้ไขก็เช่นกัน (ยังไม่ลบจนกว่าจะเลือก)
- ประวัติการแก้ไขของแต่ละงาน (ใคร แก้อะไร เมื่อไหร่) และปุ่ม "ใช้ค่านี้" เพื่อย้อนค่า
- รายการที่ถูกลบ: ดูทุกอย่างที่ถูกลบในทีม และกู้คืนพร้อมรายการที่ถูกลบไปด้วยกัน
- แจ้งว่ามีคนกำลังแก้: ระหว่างที่มีคนแก้งานในหน้ารายละเอียด คนอื่นจะเห็น "🔒 … กำลังแก้งานนี้"
  (และที่ชื่อใน WBS) กด "แจ้งเมื่อแก้เสร็จ" ได้ และไม่ถูกห้ามแก้
  ล็อกหมดอายุเอง (ไม่มีสัญญาณ 5 นาที หรือไม่ได้พิมพ์ 10 นาที)
- ของส่วนตัวยังเป็นของแต่ละคน: รายการวันนี้, Highlight, กิจวัตร, การย่อแถว และการตั้งค่า
- ออกจากโหมดทีมแล้ว ข้อมูลล่าสุดยังอยู่ในเครื่อง
